# בדיקות

## איך מריצים

```powershell
npm test                 # 86 בדיקות שרת ויחידה (node:test, D1 בזיכרון, Reem.bi מדומה)
npm i --no-save playwright
npx playwright install chromium
npm run test:e2e         # 13 תרחישים בדפדפן אמיתי מול wrangler dev
```

ב-GitHub Actions שתי הקבוצות רצות על כל PR (`.github/workflows/ci.yml`). צילומי מסך ודוחות axe נשמרים כ-artifact.

## מה מכוסה

**שרת (tests/unit):**
- יצירת מפלגה.
- מניעת מפלגה שנייה: בשרת, ביצירות מקבילות ובאילוץ המסד.
- שם תפוס, שמות רשמיים, נתונים חסרים ושמות ארוכים בעברית.
- XSS.
- שמירת טיוטה של מצע, הנהלה וקמפיין.
- אדם אמיתי בלי אישור.
- פרסום: מפלגה חסרה, פרטית, לא בדף הבית.
- שינוי נתיב עם הפניה, נתיבים שמורים, קישור בלי לוכסן.
- הרשאות בעלים מול משתמש אחר.
- ניסיון לשנות בעלים או סטטוס.
- מפלגה חסומה.
- שירות התחברות לא זמין (503).
- מקור זר.
- מחיקה והקמה מחדש, ונתיב שמור אחרי מחיקה.
- טפסים: הצטרפות, שליחה כפולה, מלכודת ספאם, אסימון מהיר או מזויף, הגבלת קצב, הסכמה, קיר תומכים בהסכמה כפולה.
- פניות, יצירת קשר ודיווחים.
- הצבעות: התחברות, קול אחד, הסתרת תוצאות, סגירה, אפשרות זרה.
- תמונות: סוג, גודל, הרשאות, SVG זדוני.
- דף בית, חיפוש וסינון, מצב ריק, sitemap, robots, 404, דפי מידע.
- כותרות אבטחה, ספירת צפיות בלי בוטים.
- מנהל: 401/403/200, מייל מזויף, CORS, מניפסט, פעולות, הסתרה, חסימה והחזרה, נבחרות, עריכת תוכן, מחיקה חריגה עם יומן, דיווחים, פניות, קטגוריות, ספרייה ותבניות.
- סמל: כל שילובי הצורה, הסגנון והסמל, וקלט זדוני.
- כל 11 תבניות הסטודיו: שם ארוך מאוד ונתונים חסרים.
- מבנה PDF תקין, כולל טבלת xref.
- גלישת טקסט עברי.

**דפדפן (tests/e2e):**
- אשף מלא בשישה שלבים, כולל הצעות, סידור מחדש, חסימת אדם אמיתי ופרסום.
- אתר ציבורי.
- העתקת קישור (נבדק מול הלוח).
- הורדת פתק PNG ודף פתקים PDF אמיתיים, ובדיקת חתימת הקובץ.
- תמונת שיתוף שנוצרת אוטומטית ומופיעה ב-og:image.
- פלייר PDF ושמונה תוצרי PNG מהסטודיו, ופרסום לגלריה.
- הצבעה ממשתמש אחר בלי כפילות.
- טפסים עם ולידציה בצד הלקוח.
- תיבת פניות ותומכים.
- משתמש אחר נחסם מהפניות.
- מנהל מול משתמש רגיל, ושינוי שנרשם ביומן.
- רוחב נייד 375px בלי גלילה אופקית.
- מצב כהה.
- axe (WCAG A/AA).
- ניווט מקלדת.
- אפס שגיאות JavaScript בקונסול.
