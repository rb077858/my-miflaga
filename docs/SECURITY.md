# אבטחה ופרטיות

המערכת **לא** מאובטחת לחלוטין, ואף מערכת לא כזאת. כאן מתועד מה נעשה, מה נבדק ומה נשאר פתוח.

## מה נעשה

| נושא | יישום |
|---|---|
| אימות | כל בקשה עם `Authorization: Bearer` נבדקת בשרת מול `https://login.reembir.com/api/userinfo` (מטמון של 60 שניות לפי גיבוב הטוקן). אין התחברות עצמאית, אין סיסמאות ואין שמירת טוקנים בשרת |
| הרשאות בעלים | כל פעולה על מפלגה מסוננת לפי `owner_id` של המשתמש המאומת. אין נקודת קצה שמקבלת מזהה מפלגה מהדפדפן לצורך עריכה |
| הרשאות מנהל | מייל שאומת ב-Reem.bi ונמצא בסוד `ADMIN_EMAILS`. לא סומכים על כותרות או פרמטרים מהדפדפן |
| ולידציה | כל קלט נבדק בשרת (`src/shared/validate.js`): אורכים, רשימות סגורות, צבעי הקס, תאריכים, הסרת תווי שליטה וכיווניות מוסתרים |
| XSS | כל טקסט משתמש עובר בריחה ב-HTML וב-SVG. בדפדפן, תבנית `html\`\`` עם בריחה אוטומטית. CSP בלי `unsafe-inline` לסקריפטים. סמלים נבנים רק מערכים מאומתים |
| הזרקת SQL | כל השאילתות עם פרמטרים (`bind`). מילות חיפוש עוברות בריחה ל-`LIKE` |
| CSRF | ההרשאה נשלחת בכותרת `Authorization`, לא בעוגייה, ולכן CSRF קלאסי לא רלוונטי. בנוסף, בקשות כתיבה עם `Origin` זר נחסמות |
| CORS | אין CORS בנקודות הקצה הרגילות. ב-`/api/admin/*` מותר רק `https://login.reembir.com`, כפי שהדשבורד דורש |
| מסגור | `frame-ancestors 'none'`, חוץ מ-`/admin/` שמותר רק ל-`login.reembir.com` |
| הגבלת קצב | מונים ב-D1 לפי גיבוב IP או מזהה משתמש: טפסים, דיווחים, יצירה, עדכון, העלאה, הצבעה ובדיקת שמות |
| ספאם | שדה מלכודת, אסימון טופס חתום ב-HMAC (מינימום 2 שניות, מקסימום 12 שעות), מפתח ייחודי לכל שליחה |
| קבצים | רק PNG, JPEG או WebP לפי חתימת הקובץ, עד 700KB. SVG ו-HTML נדחים. ההגשה כוללת `nosniff` ו-`CSP: sandbox`. התמונה מוקטנת ומקודדת מחדש בדפדפן, מה שמסיר גם מטא-דאטה כמו מיקום |
| סודות | אין סודות במאגר. `ADMIN_EMAILS` ו-`RATE_SALT` הם Secrets ב-Cloudflare וב-GitHub |
| לוגים | שגיאות נרשמות בלי טוקנים (גם כותרת `Bearer` מוסתרת) ובלי תוכן פניות |
| פרטיות | תומכים בלי מייל וטלפון. שמות מוצגים רק בהסכמה כפולה. הצבעות: הבעלים רואים רק סיכומים. IP שמור רק כגיבוב עם מלח |
| כותרות | HSTS, `Referrer-Policy`, `Permissions-Policy`, `X-Content-Type-Options` |
| התחזות | חסימת שמות של מפלגות אמיתיות וגופים רשמיים, נתיבים שמורים, וסימון "לא רשמי" בכל דף ובכל תוצר |

## מה נבדק אוטומטית

ראו [TESTING.md](TESTING.md). בין היתר:
- משתמש שמנסה לערוך, לפרסם או למחוק מפלגה של אחר.
- שינוי `owner_id`, `featured` או `status` דרך עדכון.
- כותרת מזויפת של מייל מנהל.
- XSS בשם ובסיסמה.
- SVG עם סקריפט שהוצהר כתמונה.
- קבצים גדולים מדי.
- אסימוני טפסים מזויפים.
- הגבלת קצב.
- שתי יצירות מקבילות.
- הצבעה כפולה.
- מקור זר בבקשות כתיבה.

## מגבלות ידועות

- **הצבעות** לא חשאיות מול המערכת: נשמר מזהה המצביע כדי למנוע כפילות. אפשר לפתוח כמה חשבונות ב-Reem.bi ולהצביע מכל אחד. התוצאות מוצגות כהומוריסטיות, לא כסקר.
- **ספירת צפיות** משוערת: כוללת צפיות חוזרות, ומסננת רק בוטים מוכרים.
- **הגבלת קצב לפי IP** חלשה מול מתקפה מבוזרת. מומלץ להפעיל גם את הגנות ה-Bot של Cloudflare (Bot Fight Mode) על הדומיין.
- **תמונות** שהועלו נגישות למי שיודע את המזהה האקראי (20 תווים), גם אם המפלגה פרטית.
- **מטמון האימות** של 60 שניות: משתמש שנחסם ב-Reem.bi עלול להמשיך לפעול עד דקה.
- `style-src 'unsafe-inline'` מותר, כי צבעי המפלגות מוזרקים כמשתני CSS. הערכים עוברים ולידציה כצבעי הקס.
- הבדיקות רצות מול D1 מקומי ו-Reem.bi מדומה. מול Reem.bi האמיתי ההתחברות לא נבדקה, כי האתר עוד לא רשום שם.
