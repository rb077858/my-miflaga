# הגדרות בדשבורד Reem.bi

נכנסים ל-https://login.reembir.com/admin, עוברים ל**אתרים** ולוחצים **+ אתר חדש**.

## 1. פרטי האתר

| שדה | ערך |
|---|---|
| מזהה (client_id) | `party-maker` |
| שם | `המפלגה שלי` |
| כתובת האתר | `https://miflaga.reembir.com/` |
| תיאור | `פלטפורמה להקמת מפלגות הומוריסטיות` |

## 2. כתובות חזרה מותרות

רושמים את כל השורות הבאות, כל אחת עם `/` בסוף:

```
https://miflaga.reembir.com/
https://miflaga.reembir.com/auth/callback/
http://localhost:8787/
http://localhost:8787/auth/callback/
```

כל ההתחברויות באתר חוזרות דרך `/auth/callback/`, ומשם ממשיכות לדף שממנו המשתמש יצא. השורות של `localhost` נדרשות רק לבדיקות במחשב, ואפשר למחוק אותן אחר כך.
אם פורסים גם ל-workers.dev, מוסיפים גם את הכתובת שלו באותה צורה.

## 3. מי יכול להיכנס

ממליץ על **פתוח**: זה אתר ציבורי להנאה, וכל משתמש מוגבל ממילא למפלגה אחת. אם רוצים קודם הרצה סגורה לחברים, בוחרים **בהזמנה**, ופותחים אחר כך.

## 4. כתובת ממשק הניהול

בהגדרות האתר, **כתובת ממשק הניהול**:

```
https://miflaga.reembir.com/admin/
```

הדף מוטמע בלשונית "ניהול האתר", ומתחבר אוטומטית דרך ה-SDK. בנוסף, הדשבורד יציג נתונים, בדיקות תקינות ופעולות מתוך המניפסט בכתובת `https://miflaga.reembir.com/api/admin/manifest`, בלי צורך להגדיר אותו בנפרד.

## 5. תוכניות ומחירים

**לא צריך ליצור תוכניות.** האתר חינמי ואינו מוכר דבר, ומגבלת "מפלגה אחת למשתמש" נאכפת בשרת ובמסד ולא דרך תוכנית. אם בעתיד תרצה תוכנית בתשלום, אפשר להוסיף אותה.

## 6. שליחת מיילים

**לא נדרש.** האתר לא שולח מיילים, ולכן אין צורך לבחור כתובת שולח או ליצור `SSO_SITE_KEY`.

## 7. סודות

- ב-Worker של האתר: `ADMIN_EMAILS` ו-`RATE_SALT`, דרך GitHub Actions (ראו [DEPLOY.md](DEPLOY.md)).
- ב-Worker של reem-sso: **אין צורך** (`FIREBASE_SA_*` לא נדרש).

## 8. מה הוסר

לא הוסר כלום. המאגר היה ריק, ולא הייתה בו התחברות, תשלומים, שליחת מיילים או דף ניהול קודמים.
