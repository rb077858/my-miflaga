# המפלגה שלי 🗳️

פלטפורמה להקמה ולפרסום של מפלגות ישראליות **הומוריסטיות**. משתמשים מתחברים דרך Reem.bi, מקימים מפלגה אחת, בונים סמל, מצע, הנהגה וקמפיין, ומקבלים אתר ציבורי עם קישור קבוע. בנוסף אפשר להפיק פתק הצבעה הומוריסטי, פלייר עם QR ותוצרים לרשתות.

> כל המפלגות באתר הומוריסטיות. הן לא מפלגות רשמיות, והאתר אינו גוף של ועדת הבחירות המרכזית.

- **כתובת מתוכננת:** https://miflaga.reembir.com
- **מזהה ב-Reem.bi (client_id):** `party-maker`
- **תשתית:** Cloudflare Worker (שרת + קבצים סטטיים) ומסד נתונים Cloudflare D1. אין Firebase ואין שירות AI בתשלום.

```

  api/owner.js             בעלי מפלגות
  api/public.js            טפסים, רשימות, הצבעות
  api/admin.js             מנהל המערכת + מניפסט
  api/images.js            העלאה והגשה של תמונות
  render/                  HTML לדפים ציבוריים

```

## הרצה מקומית ב-Windows

צריך להתקין [Node.js 22](https://nodejs.org/) (גרסת LTS). אחר כך, ב-PowerShell בתיקיית הפרויקט:

```powershell
npm install
copy .dev.vars.example .dev.vars
npm run dev
```

האתר ייפתח בכתובת http://localhost:8787. ההתחברות המקומית עובדת מול Reem.bi האמיתי, אם רשמתם שם את `http://localhost:8787/` ככתובת חזרה.

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | בנייה, עדכון המסד המקומי ושרת פיתוח |
| `npm test` | בנייה ובדיקות שרת ויחידה |
| `npm run test:e2e` | בדיקות בדפדפן (דורש `npm i --no-save playwright` ו-`npx playwright install chromium`) |
| `npm run deploy` | פריסה ידנית (בדרך כלל עדיף דרך GitHub Actions) |
